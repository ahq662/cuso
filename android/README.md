# CUSO 语音 Android（M7 已完成）

## 环境

| 项 | 值 |
|----|----|
| JDK | 17 |
| Android SDK | 35 |
| Gradle | 8.9（wrapper 指向腾讯镜像） |
| 包名 | `com.cuso.voice` |
| minSdk / targetSdk | 26 / 35 |
| 实测机型 | Redmi K70 Pro（arm64-v8a） |

> 项目路径含中文，已在 `gradle.properties` 加 `android.overridePathCheck=true`。
> APK 仅打包 `arm64-v8a`，约 33MB。

## 构建 / 安装

```powershell
cd android
.\gradlew.bat assembleDebug

adb reverse tcp:3000 tcp:3000
adb install -r app-debug.apk
adb shell am start -n com.cuso.voice/.MainActivity
```

App 默认请求 `http://127.0.0.1:3000`，必须保留 `adb reverse`。

## 已知限制

- 音频路由只做了「扬声器 / 听筒」，没有独立蓝牙选择；蓝牙 SCO 可能抢占麦克风，测试时建议先关蓝牙。
- 后台/锁屏通话、通知栏控制还未做（M8）。
- 安卓本地闭麦不广播给 Web（Web 的 `muted` 仅表示强制闭麦）。

### M8
- **App 级 VoiceSession**：Agora 与 presence 不再依赖页面生命周期
- **前台服务** `VoiceService`（microphone 类型）+ 常驻通知
- 通知动作：**闭麦/开麦**、**退出**
- **锁屏/切后台继续通话**（服务保活，通知常驻）
- **返回/左上角箭头 = 最小化**，语音继续；**底部「退出」= 离开语音**
- **进 App 自动回到当前语音房**；首页显示「正在语音 · 点击返回」横条
- **断线恢复**：强杀后重开 App 会自动重进并重连；服务被系统重启时发「通话已中断，点击恢复」通知
- **音频输出选择**：扬声器 / 听筒 / 蓝牙 / 耳机
- **来电处理**：响铃/接通时自动闭麦，挂断后恢复
- 通知权限（Android 13+）、前台服务麦克风权限、电话状态权限
- 注意：按**返回键**会退出语音；按 **Home 键**会保持后台通话

## 已知限制

- **进程被杀后无法在后台静默自动重连**：Android 14+ 限制后台启动麦克风前台服务；重开 App 会自动恢复，系统重启服务时会发「通话已中断」通知
- 通知动作需要在手机上手动点；adb 广播会被 `exported=false` 拦截
- 蓝牙/耳机选项需要先连接对应设备，否则提示「未检测到」
- 来电处理逻辑已接入，尚未在真实来电中验证
- 音频焦点仍以 Agora 默认行为为主
